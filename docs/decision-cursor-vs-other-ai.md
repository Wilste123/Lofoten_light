# Cursor coach repo vs other AI options

## This repo + Cursor agent

**Best for:** William’s situation—experienced cyclist, long-running Xtri-pondus context, TrainingPeaks workflow, and wanting **memory** (profile, zones, plans) in git.

| Strength | Limit |
|----------|--------|
| Persistent athlete + project context | You need to open Cursor / Cloud Agent on this repo |
| Workout YAML → ZWO, CSV analysis scripts | No automatic TrainingPeaks sync without partner API |
| Can pull Xtri docs into `docs/xtri/synced/` | You must provide repo URL or paste docs |
| Editable plans and audit trail in git | Not a mobile “coach app” on its own |

## Generic chat (ChatGPT, Claude web, etc.)

**Best for:** one-off questions, race-week nerves, explaining concepts.

**Weak for:** remembering your FTP history, Xtri phase details, and last month’s plan unless you re-upload every time.

## TrainingPeaks / TrainerRoad / Garmin AI features

**Best for:** calendar-native planning and device sync.

**Weak for:** cross-tool reasoning with your **Xtri codebase/docs** and custom scripts.

## Human coach

**Best for:** accountability, race strategy, adjusting when life goes sideways.

**Complements** this repo: agent drafts weeks; coach reviews monthly.

## Recommended hybrid

1. **This repo** — planning, workout design, exports, analysis, Xtri alignment.  
2. **TrainingPeaks** — calendar, compliance, CTL charts.  
3. **Optional** — short weekly check-in with a human coach or a generic AI only for quick questions on the go.
