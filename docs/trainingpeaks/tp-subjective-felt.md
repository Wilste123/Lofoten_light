# TrainingPeaks — subjektive felt (William)

**For agent og fremtidige analyser:** ikke bland disse.

## «Strong» / «Very Strong» / «Weak» (øktfølelse)

- Feltet beskriver **hvordan økta føltes i etterkant** (helhetsinntrykk, «beina», energi).
- **Det er ikke RPE** og **ikke** intensitet i drag.
- **Very Strong** på en **6×5 Z2** betyr **ikke** «du løp intervall for hardt» — det kan bety «jeg følte meg sterk / alert / fornøyd», eller at kroppen var **frisk nok til å fullføre med overskudd**.
- **Strong** på svøm teknikk kan bety «bra fokus», ikke CSS-hardhet.

**Agent:** Tolke **HR, pace, watt, TSS, RPE-felt (hvis fylt)** for intensitet. Bruk Strong/Very Strong kun som **kontekst** («følte seg bra tross lav TSB» / «tung uke men god stemning»).

## RPE (1–10)

- Eget felt når du fyller det — **per økt eller per intervall** avhengig av TP/Garmin.
- Dette er **nærmest** intensitetsopplevelse; sammenlign med planlagt RPE i økttekst.

## Compliance / grønn–rød

- **Grønn** = gjennomført (eller innenfor toleranse).
- **Rød** = ikke gjort / ikke matchet — **ikke** automatisk «dårlig trener».

## Wellness (vekt, søvn, HRV i TP)

- Kan komme fra Garmin; **overnight HRV** i klokke kan avvike Intervals snapshot — stol på **morgen/overnight** ved konflikt.
