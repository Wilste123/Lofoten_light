## Ærlig innrømmelse (agent)

**Forrige notat** anbefalte **mer CSS / 8×100 hard / S12** for å «heve swim speed skill». For **William nå** (lav svøm-erfaring, teknikk som **bryter sammen etter ~200 m** på lange harde drag) var det **for tidlig** og **i konflikt med eget repo**:

- [`workouts/sessions/swim.md`](../../workouts/sessions/swim.md): **S05** — *«Uten CSS: Ikke kjør — erstatt med S03 eller S04.»*  
- **S03** = **3×500** @ RPE 5–6 — **ikke** når **500 m ikke holdes** teknisk.  
- [`knowledge/coach/coach-filosofi.md`](../../knowledge/coach/coach-filosofi.md): *«Smerte som **endrer teknikk** → stopp hard økt.»*  
- [`knowledge/svom/trening-og-periodisering.md`](../../knowledge/svom/trening-og-periodisering.md): **Teknikk → Aerob → CSS**, **+10 % meter/uke**.

**Du hadde rett:** **Tvungen 500 m / CSS-blokker med kollaps** = **ødelagt økt** = **10000 t feil** (mange dårlige repetisjoner). **VM-nivå** = **høy kvalitet per repetisjon**, ikke **hardest mulig sett**.

## Hele opplegget til 6. des — «tren som VM» ærlig

**VM** = **polarised volume + få harde økter med kvalitet + lang horisont** — **ikke** «samme økt som Phelps uke 1».

### Det dere **treffer** (elite-prinsipp)

1. **Periodisering** load–load–recovery–build — **ikke** naiv linearitet.  
2. **Sykkel** SS + FTP + lang Z2 — **elite endurance base** for syklistcomeback.  
3. **Løp** intervallprogresjon **6×3 → 6×4** — **klassisk aerob power**.  
4. **Svøm 3×** med **teknikkdominans** — **riktig** for **svakeste ben**.  
5. **Styrke 2×** — MSK for **750–800 t**.  
6. **Plan B / HRV** — **profesjonell** (ikke «mer når rød»).

### Det som **fortsatt** er feil (10000 t-feil risiko) — **uendret etter rev. svøm**

| Feil | VM-kontrast |
|------|-------------|
| **6×3 + 2 t sykkel samme lør** | Elite **separator** hard / long |
| **Dobbel FTP** (nov + des) | Elite **tester** når **fresh**, ikke **2×/mnd** uten grunn |
| **Jage compliance på røde økter** | Elite **dropper** økt — **kontinuitet uka etter** |
| **Z2 «Very Strong»** på rolig | Elite **discipline** på easy |
| **Agent: 6×5 = hard løp** | **Feil mindset** — mandag er **strukturert aerob** ([`intervaller-og-fart.md`](../../knowledge/lop/intervaller-og-fart.md)) |

### Det som **ikke** er feil (ikke brems unødig)

| Du frykter | Realitet |
|------------|----------|
| «For lite svøm-hardhet» | **Hardhet = 6×50 med form**, ikke **500 m junk** |
| «For mye volum» til 6. des | **PMC** er **ambisiøs** men **innenfor** comeback **hvis** recovery **ekte** |
| «For lite VM» | **VM bygges 2027** — **nov–des** er **base**, ikke **spiss** |

## Konkret progresjon svøm (nov–des, **uten** å endre spikrede timer)

1. **Uke 1–2:** 2× teknikk + 1× **aerob form** (f.eks. **4×100 @ RPE 5**, 15 s pause — **stopp** hvis teknikk glipser).  
2. **Uke 3–4:** Når **800 m totalt/økt** føles ok → **3×200** eller **S03b** 3×400.  
3. **Når 400 m kontinuerlig** (eller 3×300 jevn) → **CSS-test** → **S05** i [`profile.md`](../../docs/athlete/profile.md).  
4. **Pull buoy** ≤ **40 %** ([`trening-og-periodisering.md`](../../knowledge/svom/trening-og-periodisering.md)).

**Erik-drill:** **Behold** — **legg til** «**4×50 full stroke med samme fokus**» etter drills (EP#255 — **nytt**).
