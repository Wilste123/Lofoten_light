# Teknikk B — skuldervennlig — 45 min

## Oppvarming (8 min)
- 300 easy alterner 50 fri / 50 rygg

## Prehab (5 min)
- 4×50 med pull buoy **kun** fokus høy albue — ingen paddles

## Main (25 min)
- 6×75: 25 catch-up / 25 fingertip / 25 swim @ 20 s
- 4×50 non-free (25 rygg / 25 bryst) @ 15 s

## Avslutning (7 min)
- 200 super smooth RPE 3

## Plan B
- Erstatt 6×75 med 8×50 drill

## TP
```
300 WU
4x50 pull buoy technique
6x75 drill progression 20s
4x50 non-free 15s
200 CD
```
