# Ernæring — coach-notater for chat (kort)

Brukes som **trimmet snippet** i coach-api sammen med `grunnlag.md` / `ibs-og-gluten.md`.

## Prinsipper

1. Underfueling er vanligere feil enn «for mye karbohydrat» ved comeback.
2. Test race-ernæring på lange/rolige økter — ikke på race-dag.
3. Personlige begrensninger (IBS, gluten, allergi) lever i **profil/avtaler**, ikke i generisk plan.
4. Coach spør; utøveren bekrefter lagring via Du / «Lagre».

## Hurtigsjekk før råd

- Har utøveren skade/sykdom som påvirker mat/væske?
- Er det kvalitet vs langøkt vs hvile i dag?
- Finnes lagrede mat-avtaler i profil?
