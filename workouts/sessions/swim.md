# Svømøkter — full preskripsjon (S01–S10)

ZWO: `workouts/zwo/swim/`. Importer per `docs/trainingpeaks/importer-lop-svom-zwo.md`. **% threshold pace** i TP etter CSS-test — uten CSS: RPE som angitt.

Meter-økning max **~10 %/uke** (`knowledge/svom/trening-og-periodisering.md`).

---

## S01 — Teknikk A (50 min, ~2000–2200 m)

**Formål:** Vane, drill, lav belastning skulder.  
**RPE:** 3–5.  
**ZWO:** `S01-teknikk-a.zwo`

| Del | Innhold |
|-----|---------|
| Oppvarming | 200 mixed (50 fri / 50 rygg / 50 bryst lett / 50 crawl) |
| Main | 8×50: 25 drill / 25 svøm — roter catch-up, fingertip, 6-kick drill, scull |
| | 4×100 pull med pull buoy @ RPE 4, 15 s pause |
| | 8×25 spark med board, 10 s pause |
| Avslutning | 100 easy |

**Plan B:** Dropp 2×50 drill; behold 4×100 pull.  
**Feil:** For høy puls → kortere pause, ikke raskere.

---

## S02 — Teknikk skulder (45 min)

**Formål:** Skuldervennlig teknikk.  
**ZWO:** `S02-teknikk-skulder.zwo`

300 lett → 6×75 (25 skulderfokus drill / 50 crawl lett) → 4×50 rygg eller drill uten smerte → 200 avslutning.

**Plan B:** Erstatt crawl med rygg på øm skulder.  
**Stopp:** Skuldersmerte >3/10 etter økta → fysio, ikke mer crawl Q den uken.

---

## S03 — Aerob 3×500 (55 min)

**Formål:** Aerob kapasitet svøm.  
**RPE:** 5–6 jevn på 500-ene.  
**ZWO:** `S03-aerob-3x500.zwo`

400 WU + 4×50 oppbygging → **3×500** @ jevn innsats, **25 s** pause → 200 CD.

**Plan B:** **S03b** 3×400 @ samme RPE.  
**Plan C:** 20 min kontinuerlig crawl @ RPE 5.

---

## S03b — Aerob 3×400 (50 min)

Lettere volum enn S03. Samme struktur, 3×400 med 20 s pause.

---

## S04 — Aerob 1500 kontinuerlig (60 min)

**Forutsetning:** 3×500 komfortabelt.  
**Main:** 1500 uten stopp — **negativ split** mentalt (2. halvpart roligere enn første hvis usikker).

---

## S05 — CSS 10×100 (60 min)

**Krever:** CSS/T-pace i `profile.md`.  
10×100 @ CSS, **10 s** pause (siste 2 kan +5 s).

**Uten CSS:** Ikke kjør — erstatt med S03 eller S04.

---

## S06 — CSS pyramide (70 min)

100–200–300–400–300–200–100 @ CSS med **20 s** pause mellom lengder.

---

## S07 — Race 1900 (55 min)

Racesim Half Extreme svøm. Oppvarming 400 + 4×50 race-følelse → **1900** i våtdrakt om mulig → 200 lett.

**Pacing:** Første 500 roligere enn du tror.

---

## S08 — OWS sim (60 min)

Sjø/brygge: 10 min land-WU → 400 sighting hvert 6. tak → 800 steady → 4×50 pickup → 400 CD.

Se `knowledge/svom/apent-vann-kulde.md` for kulde.

---

## S09 — Recovery (35 min)

RPE 2–4. 300 + 6×50 lett + 4×100 pull + 200.

---

## S10 — Pust og frekvens (45 min)

**Formål:** Rolig frekvens, utholden pust — ikke meter-hero.  
**ZWO:** `S10-breath-control.zwo`

300 WU → 6×50: 3/5/7 slag per pust roterende → 4×100 @ RPE 4 med fokus utpust under vann → 6×25 avslappet → 100 CD.
