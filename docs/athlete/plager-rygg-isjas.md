# Rygg, isjasnerven, ankel — William (coach-notat)

**Kilde:** William sep 2026 — bruk **hans ord**, ikke feildiagnose i planer.

## Hva dette er (og ikke er)

| | |
|---|---|
| **Er** | **Ryggproblem** (ofte lumbalt / belastning fra stillesitting + comeback) som kan gi symptomer langs **isjasnerven** (prikking, stramhet bak lår, «nerve-trekking») |
| **Er ikke** | Primært «hamstring-iskias» eller «du må bare strekke hamstring» — unngå å programmere økter som om det bare er bakside lår |

**Isjas** = isjion / nerveforløp fra rygg — coachen skriver **isjasnerven / rygg**, ikke «iskias» som kortkode i Intervals eller økttekst.

## Treningsregler (styrke og løp)

1. **Rygg først:** nøytral rygg på maskiner, kontrollert tempo, ingen hero i markløft/RDL tidlig i comeback.
2. **Isjasnerven:** stopp øvelse ved økning av prikking, kribling eller «elektrisk» trekk **fra rygg** — ikke tren gjennom.
3. **Ankel:** dorsiflex og calf for løp — hjemme i ST04 (ingen apparater nødvendig).
4. **Støt / løp:** gradvis volum; styrke beskytter, men ikke tung ecc hamstring samme uke som ny bakke-Q uten grønt lys.
5. **Kjerne:** **hjemme** (bird dog, sideplanke, dead bug) — ikke maskin-core på 3T.
