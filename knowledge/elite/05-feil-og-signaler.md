# Feil og signaler — lær fra feiltolkninger

---

## Agent / coach-feil (fix permanent)

| Feil | Riktig |
|------|--------|
| **6×5 mandag = hard løp** | **Z2 struktur** — telles **ikke** mot cap 2 harde løp |
| **Svøm: press CSS/500 m tidlig** | **Teknikk stabil først** — dårlige reps = minus |
| **«For mange harde løp» når man 6×5 + fre 6×3** | **Én** hard løp — **3 tri-Q** er **ønsket** i base |
| **PT-Arvid: 1 Q/uke** | **3 Q/uke** når grønn — se `00-FILOSOFI.md` |
| **2019-FTP / 20 t uke 3** | Comeback-dose +10 %/uke |
| **Grønn TP = kjør hardt** | HRV/søvn/bein **overstyrer** |
| **Junk threshold på easy** | Sagan: **friskhet** og Z2-ærlighet |

---

## William-typiske fallgruver

| Symptom | Fix |
|---------|-----|
| «2019-kroppen er tilbake» | 3 uker stabil 10–11 t før 14 t snitt |
| Sykkel unngår svøm | **Svøm først** i ukeplan |
| 5 løp/uke for gøy | Cap **harde** løp 2; 4. løp = 30 min Z1 |
| Hero brick tidlig | `brick-og-overgang.md` (arkiv) |
| Intervaller på gjetning-FTP | Test + HR/RPE |
| Ignorere søvn for CTL | 3–5 dager dempet intensitet |
| Race nutrition første gang på start | 60–90 g CHO/t på 4 h+ i build |

## Smerte og sykdom

- **Teknikk-endrende smerte** → stopp hardt, ikke «push through».  
- Iling vs krise — praktiske regler i arkiv `skader/`.  
- **Ingen medisinsk diagnose** — henvis.

## Coach-setninger (elite)

- «Lofoten krever at du tåler **flere** harde **dager** i uka — ikke **flere** harde **løp** på mandag som allerede er rolig struktur.»  
- «Du liker løp — bra. **Fre** er løp-Q; **man** er **6×5**, ikke bonus-intervall.»  
- «Sener bygges med **volum + få skikkelige Q** — ikke med feil telling.»
