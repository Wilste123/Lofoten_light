# Kvalitet og intensitet — hva som teller som «hard»

**Formål:** Unngå PT-feil (for lite Q) **og** Strava-feil (for mye grå sone / feil telling).

---

## Ukentlig gulv (toppidrett, comeback-dose)

| Fase | Harde **stimulus**-dager/uke (totalt tri) | Merknad |
|------|-------------------------------------------|---------|
| Re-etablering | **2** | Minst én per ben over 14 dager |
| Base (nov–apr) | **3** | Typisk: **sykkel SS/THR** + **løp intervall/tempo** + **svøm** (teknikk-Q eller kort hard) |
| Recovery-uke | **1–2** | Lett SS eller korte drag — **ikke** null i måneder |
| Build | **3–4** | + brick; **maks 2 harde løp** |

**Forbudt mønster:** én intervalløkt/uke + resten «gåtur» — unntatt sykdom/taper.

---

## Løp

| Type | Eksempler | Teller som **hard løp**? |
|------|-----------|---------------------------|
| **Strukturert aerob** | **6×5 min Z2/sub ~150**, 60 min rolig med lap | **Nei** |
| **Aerob power** | **6×3, 6×4, 5×4** @ RPE 7 | **Ja** |
| **Terskel/tempo** | 4×5 @ terskel, 20–30 min kontinuerlig threshold | **Ja** |
| **OPV-signatur** | elghufs, myr-løp (terreng Z2 med struktur) | **Nei** (med mindre preskribert RPE 7+) |
| **Bakke hard** | **5×2** @ RPE 7+ | **Ja** |

**Cap:** **Maks ~2 harde løp/uke.** Mandag 6×5 **telles ikke**.

**Plan B mandag:** 4×5 eller 40 min Z2 — **ikke** «dropp fordi du har 6×3 fre» uten HRV/skade-grunn.

Arkiv: `workouts/planned/run/`, `opv-nokkelokter.md` (signaturøkter).

---

## Sykkel

| Q-type | Eksempler |
|--------|-----------|
| Sweet spot / threshold | SS 2×20, 3×15, 4×8 @ ~90 % FTP |
| Test | FTP ramp (når fresh — **ikke** dobbel test uten grunn) |
| Variasjon | crisscross, 18×3 (fase-egnet) |

**Ikke:** recovery-uke med R11 **og** FTP **og** SS samme uke uten Plan B.

---

## Svøm

| Fase | Q-innhold |
|------|-----------|
| Nå (re-etab) | **S01/S02** teknikk + **4×50 full stroke** etter drill |
| Aerob form | **4×100**, **3×200** @ RPE 5–6 — **stopp** når teknikk glipser |
| Kort hard | **6×50**, **8×25 build** @ RPE 7 **kun** når 50 m fine |
| Gate | **~800 m kontinuerlig** → **CSS-test** → **S05** |

**Ikke:** 3×500 @ RPE 6 når form kollapser etter 200 m.

---

## Intensitetsfordeling (faglig)

**[ESTABLISHED]** Seiler/Tønnessen: stor andel **≤ VT1**; **~2 HIT/terskel-økter/uke** ved 10–14 økter — mer gir sjelden ekstra, øker overreaching.

**[OLT / 2025 coach study]** Norsk elite: ofte **80–90 %** lav intensitet + **2–3 nøkkeldager**; **double threshold** finnes (tri/løp/svøm) — **William base 2026:** en nøkkel per ben, ikke Blummenfelt-dobbel hver dag.

---

## Z2-ærlighet (Sagan-regel)

- Rolig sykkel/løp: **RPE 3–4**, HR i **Z2**, ikke «Very Strong» for compliance.  
- **TSS på junk threshold** = elite-feil.

## 3 kvalitetsøkter — eksempel base-uke

| Dag | Økt | Rolle |
|-----|-----|-------|
| Man | 6×5 løp | **Aerob struktur** |
| Tir | SS sykkel | **Sykkel-Q** |
| Ons–tor | svøm teknikk + lett | volum |
| Fre/lør | 6×3 løp | **Løp-Q** |
| … | lang Z2 sykkel søn | volum |

= **2 harde løp?** **Nei — én** (6×3). **3 stimulusdager** totalt (man telles som volum-struktur, tir SS, fre/lør løp).

Agent: ** ikke ** kalle dette «for mange harde løp ».
