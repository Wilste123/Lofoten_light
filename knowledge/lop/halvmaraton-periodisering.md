# Halvmaraton — periodisering (løpsfokus)

For utøvere med **halvmaraton / 21 km** som hovedmål — ikke tri-ukemaler.
Les med `load-and-intensity.md`, `lop/oppbygging-etter-pause.md`, `lop/ukeplaner-lav-frekvens.md`.

## Prioritering

Kontinuitet → skadefrihet → aerob km → én kvalitetsøkt → langtur → race-pace.
Ikke kopier tri-uke (svøm/sykkel) med mindre avtalen eksplisitt inkluderer dem.

## Sesongfaser (typisk 16–28 uker til HM)

| Fase | Uker (ca.) | Fokus | Hard løp | Langtur |
|------|------------|-------|----------|---------|
| Etablering | 3–6 | Vaner, styrke, easy | 0 (kun strides) | 40–55 min |
| Base | 6–10 | Aerob volum | 0–1 | 60–80 min |
| Build | 4–8 | Terskel / bakke / HM-pace | 1 | 75–100 min |
| Peak | 2–3 | Race-spesifikk | 1 | topp −10 % |
| Taper | 1–2 | Frisk til start | kort skarphet | kort |

**Volumregel:** øk langtur eller ukentlig tid ~5–8 %/uke, ikke begge hardt samme uke.
Cut-back (~−25–35 %) hver 3.–4. uke i base/build.

## Intensitet (80/20)

- ~80 % av løpetid under terskel (RPE 4–5 / samtale).
- Max **1 hard løpeøkt/uke** i base; **1** i build (ikke 2 før stabil base).
- Strides (6–8×15–20 s) teller som nevromotorikk, ikke «hard dag».

## Styrke i HM-sesong

- **2×/uke** ideelt i etablering/base; **1×/uke** OK ved 3 økter totalt.
- Prioriter: hofte/sete, én-bens stabilitet, magestabilitet, lettere plyo sent i base.
- Ikke tung knebøy dagen før langtur eller Q.
- Se `lop/styrke-og-lop.md` + `skader/forebygging-styrke-mobilitet.md`.

## Ukeeksempler (kun løp + styrke)

### 3 økter/uke (tidsklemma / avtale)

| Dag | Økt | Formål |
|-----|-----|--------|
| Man | Easy 35–45 min | Kontinuitet |
| Ons | Styrke 30–40 min | Skadefrihet |
| Lør | Lang easy / easy+strides 50–75 min | Aerob + progresjon |

Hviledager mellom — ikke fyll kalenderen.

### 4 økter/uke

| Dag | Økt |
|-----|-----|
| Man | Easy 40 |
| Ons | Styrke ELLER easy + strides |
| Fre | Easy 35–45 ELLER lett Q (build) |
| Søn | Langtur |

## Race-spesifikt (siste 6–8 uker)

- 1×/uke blokk @ HM-følelse (RPE 6–7): f.eks. 2×12–20 min eller 3–5 km kontinuerlig.
- Langtur: siste 15–25 min kan nærme HM-pace når skadefri.
- Ikke ny økt-type i taper.

## Anti-mønstre

- Daglig løp uten styrke ved comeback.
- Threshold hver uke fra uke 1.
- «Halvmaraton = halvparten av maratonvolum» uten å sjekke skadehistorikk.
- Svøm/sykkel-fyll fordi biblioteket har økter — kun hvis avtalen sier det.
