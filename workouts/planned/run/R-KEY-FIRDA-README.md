# FIRDA — tre nøkkel løp-Q (William)

**Prinsipp:** **Tre ulike stimulus** — ikke samme økt med feil label.

| Fil | Rolle | Drag | Intensitet |
|-----|--------|------|------------|
| `R-KEY-FIRDA-6x4.txt` | **Aerob power** | 6×4 min | ~90–96 % LTHR, RPE 7 |
| `R-KEY-FIRDA-4x8-terskel.txt` | **Terskel (cruise)** | 4×8 min | ~96–100 % LTHR, RPE 7–8 kontrollert |
| `R-KEY-FIRDA-5x3-vo2.txt` | **VO2** | 5×3 min | ~105–112 % LTHR, RPE 8–9 |

**Rotasjon (base 2 / build):** **maks 1** av terskel og VO2 samme uke; **6×4** kan stå oftere (fre i base 1).  
**Recovery-uke:** 5×4 aerob power **eller** dropp VO2/terskel.

**Gammel TP 6×4** (7 drag, pause 86–94 %): **kast** — bruk FIRDA 6×4 aerob power.

Se `02-Oktoppbygging` (exports/treningsguider): én utviklingsoppgave · ekte pause · Plan B.
