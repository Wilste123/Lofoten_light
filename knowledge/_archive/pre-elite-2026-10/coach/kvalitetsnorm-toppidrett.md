# Kvalitetsnorm — toppidrett (William / Half Extreme)

William trener mot **ekstrem triathlon** (750–800 t, 14–16 t/uke i build), ikke «3 timer til Arvid på 60». Agenten skal planlegge som **elite-orientert utholdenhet**, med comeback-filter på **dose** — ikke på **ambisjon**.

## Ukentlig kvalitet (gulv, ikke tak)

| Fase | Økter/uke med **reell** stimulus (Z3–Z5 / race-relevant) | Fordeling |
|------|----------------------------------------------------------|-----------|
| Re-etablering (etter kontakt) | **2–3** | Minst **én per ben** over 14 dager: svøm + sykkel + løp |
| Base (nov–apr) | **3** | Sykkel SS/THR · løp intervall/tempo/bakke · svøm CSS/aerob hard |
| Build (mai–jul) | **3–4** | + brick, lang sykkel med race-blokker |
| Recovery-uke | **1–2** | Lett SS eller korte drag — **ikke** null kvalitet hele måneden |

**Forbudt mønster:** «Én intervalløkt i uka, resten gåtur» utenom eksplisitt taper/sykdom.

## Hva teller som kvalitet

| Ben | Eksempler (repo-ID) |
|-----|---------------------|
| Sykkel | SS 2×20 / 3×15, FTP-test, crisscross, 4×8 min @ 90 % FTP i langtur |
| Løp | OPV elghufs/myr, 5×3, 5×2 bakke, tempo 4×5 min, strides + 4×90 s |
| Svøm | CSS-test, 10×100 @ CSS, 8×100 hard, 6×200 @ RPE 7, negativ split 1500 |

**6×5 min mandag (Z2/sub ~150)** er **strukturert aerob volum** — teller **ikke** som «hard løp» i cap **maks 2/uke** (se `knowledge/lop/intervaller-og-fart.md`).

Z2-langturer er **nødvendig volum**, ikke erstatning for tabellen over.

## Comeback-filter (ikke PT-filter)

| PT-feil (for puslete) | Toppidrett med comeback |
|----------------------|-------------------------|
| 1× intervall/uke «så vi ikke overtrener» | 3× kvalitet/uke når søvn og ACWR er ok |
| Unngå all smerte | Stopp ved **teknikk-endrende** smerte; ellers doser |
| Samme uke: 3 harde løp | **Maks 2** harde løp/uke; roter sykkel/svøm-Q |
| Oktober 2019-volum uke 3 | +10 % timer/uke-regel, mengde-mesos |

## Planleggingsrekkefølge

1. Legg inn **alle kvalitetsøkter** (svøm, sykkel, løp) — se `ukemaler.md` fase B/C.  
2. Fyll **Z2** rundt dem (lang sykkel, lang løp, teknikk).  
3. **Styrke** 2× — ikke kutt for å «spare tid» til mer Z1.  
4. Sjekk **timer** mot `mengdeperioder-2026-2027.md` — øk Z2 før du kutter Q.

## OPV / William

Ole Petter: struktur og ærlighet. Toppidrett: **du skal bli svett** flere dager i uka. Kommenter i TP **hvilke Q** som satt — ikke bare «rolig uke».

Se `coach-filosofi.md`, `feil-og-fixes.md` §9, `plans/mengdeperioder-2026-2027.md`.
