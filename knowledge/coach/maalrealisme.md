# Målrealisme — vurdering av gjennomførbarhet

**Formål:** I setup-chat, plan-preview og Du→justering skal coachen **ærlig** vurdere om mål × tid × kapasitet henger sammen — og foreslå alternativer når det ikke gjør det.

**Evidensnivå:** Dimensjonene (treningsalder, dose, tid til adaptasjon, load-spike-risiko) = *konsensus*. Konkrete «uker til X»-tabeller = *praksis-heuristikk*, ikke prediksjonsmodell. Tidmål (f.eks. «sub-1:30») er *usikre* uten nylige tester — si det.

**Ikke:** Hardkode enkeltscenarioer i kode. Bruk prinsippene + eksemplene som mønster.

## De fem aksene

Vurder **alle** før du sier «ja» til et race-/tidmål:

| Akse | Spørsmål | Svake signaler | Sterke signaler |
|------|----------|----------------|-----------------|
| **1. Erfaring / treningsalder** | Har de gjort *lignende* distanse/disiplin før? | Første tri, første HM/maraton, kan ikke svømme | Fullført lignende race; år med struktur |
| **2. Nåværende form / konsistens** | Trener de *nå*, jevnt? | Pause måneder–år; 0–1 økt/uke; «dårlig form» | ≥8–12 uker jevn trening; form OK |
| **3. Dose (økter × timer/uke)** | Hva er realistisk *de fleste* uker? | 2 økter; &lt;3 t/uke mot long-course | 4–6+ økter; timer matcher distanse |
| **4. Tid til race** | Uker til start? | Kort prep til ny, lang distanse | Nok uker til base→build→taper |
| **5. Måltype** | Fullføre vs tid vs plassering? | Agressivt tidmål uten fasthistorikk | «Fullføre sunt» / tid basert på nylig test |

**Produktregel:** Lav skår på **flere** akser samtidig → mål er sannsynlig urealistisk *som formulert*. Én svak akse kan ofte kompenseres (mer tid, enklere mål, annen distanse).

## Hvorfor dette er evidensbasert (ikke «magfølelse»)

1. **Adaptasjon tar tid.** Aerob kapasitet, sener/bein og teknikk endres over uker–måneder, ikke dager (klassisk treningsfysiologi; progressive overload / ACSM FITT).  
2. **Dose–respons med tak.** Mer trening gir typisk mer adaptasjon *opp til et punkt*; deretter øker skade- og utbrenthetsrisiko (IOC load consensus, Soligard et al. *BJSM* 2016; Gabbett 2016). Å «presse inn» half-prep på 2 økter/uke ved å gjøre dem ekstremt harde er nettopp spike-logikk — frarådes.  
3. **Spesifisitet.** Prestasjon på tri/HM/maraton krever relevant stimulus (svøm+sykkel+løp / langtur). Generell kondis alene predikerer dårlig (treningsspesifisitet).  
4. **Tidsmål er støyfulle.** Uten nylig terskel-/race-data er tidsprognoser usikre; ærlige intervaller &gt; punktestimat (applied physiology / coaching consensus).  
5. **Første gangs hendelse.** Noviser har høyere skadeinsidens ved brå km-økning (løpsepidemiologi; load-spike). Completion-mål er da mer forsvarlig enn aggressive tidmål.

## Heuristisk «realisme-matrise» (*praksis*)

Tell **røde flagg** (0–5). Dette er coach-verktøy, ikke fasit-algoritme.

| Rødt flagg hvis … |
|-------------------|
| Erfaring: ingen lignende distanse/disiplin (f.eks. første tri uten svømmevane) |
| Form: &lt;6–8 uker jevn trening *eller* eksplisitt dårlig/comeback uten base |
| Dose: økter/uke eller timer åpenbart under det distansen krever (se tabell under) |
| Tid: for få uker til å bygge base uten farlig spike (se minimumsvinduer) |
| Måltype: tid-/plasseringsmål uten nylig relevant fasthistorikk |

| Flagg | Coach-respons |
|-------|----------------|
| 0–1 | Mål OK; nevne én risiko |
| 2 | Mål *mulig* med justert forventning (fullføre &gt; tid) eller mer dose/tid |
| 3 | **Ikke** lov mål som formulert — foreslå alternativ (se under) |
| 4–5 | Stopp: nytt mål + trygg dose; ellers høy skade-/fiaskorisiko |

### Minimum dose-retning (*praksis*, ikke lov)

| Mål | Ofte for lite | Mer bærekraftig retning |
|-----|---------------|-------------------------|
| Første 5–10 km | 1 økt/uke | 2–3 økter over ≥8–12 uker |
| Første HM | 2 økter, &lt;12 uker, ingen langtur-vane | 3–4 økter, ≥16 uker, langtur-progresjon |
| Første maraton | 3 økter, &lt;20 uker, ingen HM-historikk | 4–5 økter, ≥24 uker, solid HM-base |
| Første sprint/OL-tri | 2 økter, kan ikke svømme | Svømmeopplæring + 3–4 økter, ≥12–16 uker |
| Første Half / 70.3 / Extreme | 2–3 økter, dårlig form, &lt;6 mnd | 4–6 økter, ≥9–12+ mnd for novise; svøm+lang sykkel |
| Agressivt tidmål (f.eks. stor PB) | Kort tid + lav dose | Enten mer tid/dose *eller* mildere tid / «A–B–C-mål» |

Tallene er **retning** for ærlig samtale — individuelle unntak finnes (sterk overførbar base fra annen idrett), men unntak må *begrunnes*, ikke antas.

### Tid til race — tommelfinger (*praksis*)

| Situasjon | Ofte for knapp tid |
|-----------|-------------------|
| Novise → half-tri på &lt;4–6 mnd med lav dose | Ja |
| Comeback (lang pause) → maraton på &lt;4 mnd | Ofte ja for *tidmål*; fullføre kan være forhandlingsbart |
| Jevnt trent løper → HM om 12–16 uker | Ofte OK for fullføre; tidmål avhenger av nivå |
| Godt trent → taper inn i kjent distanse | OK |

## Målhierarki (foreslå alltid ved tvil)

1. **A — helse/kontinuitet:** skadefri, avtalte økter over X uker.  
2. **B — gjennomføring:** fullføre distansen / race med kontroll.  
3. **C — tid:** kun hvis A+B og nylig data støtter det.  

Si eksplisitt: «A er ikke-forhandlingsbart; B er sesongmål; C er bonus.»

## Alternativer når målet ikke holder

Ikke bare si nei — **bytt én eller flere akser**:

| Justering | Eksempel |
|-----------|----------|
| Senere dato | Samme race neste år / høst i stedet for mai |
| Kortere / enklere format | Sprint før half; 10 km før HM; HM før maraton |
| Mildere suksesskriterium | Fullføre &gt; sub-X; «gå-jogg OK» |
| Øke dose *realistisk* | 2→3–4 økter *før* man lover long-course |
| Byggesteinsesong | År 1: svøm + aerob; år 2: half |
| Behold dato, endre idrettsmål | «Tri-debut» → «svømme 1000 m + sykkel-granfondo» samme vår |

## Eksempler (mønstre — ikke hardkodede fasitsvar)

Bruk samme *metode* på nye case.

### Eksempel A — for aggressivt
- Første triatlon · dårlig form · 2 økter/uke · Half i mai (få måneder) · tidmål.  
- Flagg: erfaring, form, dose, tid, måltype → **4–5**.  
- Respons: Nei til half-i-mai som A-mål. Alternativ: svømmeopplæring + 3 økter; sprint/kort lopp høsten *eller* half neste sesong; A-mål = kontinuitet.

### Eksempel B — forhandlingsbart
- Tidligere HM · form OK · 4 økter/uke · maraton om 18 uker · «finne ut av tid».  
- Flagg: 0–1 (ny distanse, men overførbar base).  
- Respons: Ja til fullføre; tid som C-mål etter 1–2 langturblokker + evt. testløp.

### Eksempel C — dose for lav til format
- Kan svømme · 3 økter/uke stabile · Half om 10 mnd · fullføre.  
- Flagg: dose litt lav men tid god.  
- Respons: Ja hvis de kan gå mot 4–5 økter i build *eller* akseptere veldig konservativ half med mye Z2; ellers sprint i år + half senere.

### Eksempel D — tidmål uten data
- Erfaren løper · 5 økter · HM om 14 uker · «sub-1:20» uten nylige løp.  
- Flagg: måltype.  
- Respons: Sett B = sterkt HM-løp; C = tidssone etter terskeltest / 10 km — ikke lås sub-1:20 i setup.

### Eksempel E — comeback-ego
- Eks-syklist · lang pause · vil «tilbake til gammel watt» på 8 uker · 6 hardøkter.  
- Flagg: form, tid, (intensitets-)dose.  
- Respons: Nei til historisk nivå på 8 uker (load-spike). Base 3–4 mnd; wattmål som C senere. Se `nybegynner-vs-trent.md`, IOC load.

## Setup-chat — påkrevd atferd

1. Samle nok om de **fem aksene** (1–2 spørsmål om gangen).  
2. Gi en **tydelig dom**: realistisk / betinget / urealistisk som formulert.  
3. Ved betinget/urealistisk: **ett anbefalt alternativ** + kort begrunnelse (load + tid + spesifisitet).  
4. Ikke smigre bort risiko («det ordner seg»).  
5. Trekk inn `periodisering-faser.md`, `ukeplaner-3-5-6.md`, `nybegynner-vs-trent.md` for *hvordan* alternativet trenes — denne filen for *om* målet bør stå.

## Plan-preview / adjust

Hvis Du endrer racedato eller frekvens nedover: **re-kjør** realistiskhetsvurdering.  
Urealistisk mål skal ikke synces som om det var godkjent.
