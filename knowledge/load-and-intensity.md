# Load and intensity (reference)

Use with William’s zones in `docs/athlete/profile.md`. Adjust when profile specifies polarized vs pyramidal preference.

## Weekly structure (experienced cyclist, tri context)

- **2 quality sessions/week** on bike is a common default during base/build; add a third only if sleep, HRV, and completion rate stay high.
- **Long ride** weekly (or biweekly in recovery weeks) anchored in Z2 with optional progressive elements late in build.
- **Recovery week** every 3–4 weeks: ~30–40% TSS reduction, keep frequency, drop intensity duration.

## Intensity distribution (starting heuristic)

| Phase | Z1–Z2 | Z3 | Z4+ |
|-------|-------|-----|-----|
| Base | 80–90% | 5–15% | 0–5% |
| Build | 75–85% | 10–15% | 5–15% |
| Specialty | 70–80% | 10–15% | 10–20% |

Triathlon: protect **run durability**—hard bike + hard run same day only when profile allows.

## TSS and CTL

- Rough bike TSS ≈ `(duration_hours) × (IF²) × 100` with IF from power or HR-based proxy.
- CTL ramp: often **5–8 TSS/week** sustainable for trained athletes; **>10** for multiple weeks increases injury/burnout risk—call out explicitly.

## Communication style for William

- Lead with **session purpose** and **key numbers**, then detail.
- Offer **Plan A / Plan B** when time or fatigue is uncertain.
