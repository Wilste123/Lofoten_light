# Teknikk A — 50 min

**Formål:** Bygge effektiv crawl uten å jage meter. William — lav svømmeerfaring, høy idretts-Q.

## Oppvarming (10 min)
- 200 mixed (50 fri / 50 rygg)
- 4×50 som 25 drill / 25 swim — **catch-up** drill
- 4×50 fingertip drag — fokus rotasjon

## Main set (30 min)
- 8×50 drill (25 skulling / 25 swim) @ 15 s pause — RPE 4
- 4×100 easy @ 20 s — RPE 5, tell slag per 50 (noter beste)

## Avslutning (10 min)
- 8×25 kick med board — lett ben
- 100 easy choice

## Plan B (35 min)
- Dropp 4×100; gjør 6×50 drill + 200 continuous easy

```
WU 200 mix + drills
```
