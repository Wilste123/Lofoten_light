# Training plans

Store meso/micro cycles as markdown, e.g. `2026-W12.md`.

Ask the agent to create a plan with:

- Week theme and target TSS range
- Day-by-day table (sport, duration, key intensity)
- Links to `workouts/catalog.md`, `workouts/sessions/`, and `workouts/zwo/*.zwo` where applicable
- Notes for TrainingPeaks library setup
