# 3×4 km — halvmaraton-utholdenhet

**Når:** Når du tåler **70–90 min** løp-Q · **ikke** samme uke som Crisscross + stor svøm.

**Sonemal:** Threshold **5:30/km** · LTHR **168**.

## Oppvarming — 20 min

Som FIRDA 4×8 (inkl. 3 min @ 96–99 % LTHR).

## Hoveddel

**3×4 km** @ **94–99 % LTHR** · **5:30–5:40/km** (RPE **7–7,5**, jevn flyt).  
**Pause 3 min** @ **75–85 % LTHR**.

**Plan B:** **2×4 km** · **3×3 km** @ samme band.
