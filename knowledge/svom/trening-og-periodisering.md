# Svømtrening — struktur og økttyper

## Økttyper

| Type | Formål | Eksempel |
|------|--------|----------|
| Teknikk | Effektivitet | 8×50 drill + 4×100 easy |
| Aerob | Grunnmur | 3×400 steady eller 30 min kontinuerlig |
| Threshold | CSS-soner | 5×200 @ CSS + 20 s pause |
| OW sim | Race | 1500–1900 kontinuerlig i wetsuit |

## CSS (Critical Swim Speed)

- Test: 400 m + 200 m (eller 400+100) med rest — beregn CSS for intervallintensitet.
- Lagre i `docs/athlete/profile.md` når testet.

## Integrasjon i tri-uke

- Legg svøm **før** hard løp samme dag, eller på separate dager tidlig i opptrapping.
- Unngå tung pull-dag dagen før mye løp hvis skuldre er ømme.

## Innendørs (Trondheim)

- Vinter: basseng er hovedarena — bruk for konsistens mot 750–800 t totalt.
