# Sykkel — intervaller og kvalitet

## Økttyper (1–2×/uke i build)

| Type | Eksempel | Formål |
|------|----------|--------|
| Sweet spot | 2×20 min @ 88–93 % FTP | Tidseffektiv threshold |
| Threshold | 2×20 @ 95–100 % | FTP vedlikehold/økning |
| VO2 | 5×3 min @ 115–120 % | Topp aerob |
| Over-unders | 2×12 min alternating | Race tolerance |

## Rekkefølge i uke

- Hard sykkel **ikke** dagen før hard løp (William prioriterer løp-skadefrihet).
- Etter tung svøm skulder-dag: lett sykkel eller rest.

## Rulle vs ute

- Intervaller: ofte rulle for presisjon.
- Lange: ute når vær tillater — håndtering og vind for Lofoten.
