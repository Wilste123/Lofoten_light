# Aerob 3×500 — 55 min

**Mål:** Bygge mot 1500 m kontinuerlig.

## Oppvarming (10 min)
- 400 easy + 4×50 build

## Main (40 min)
- **3×500** @ RPE 5–6, pause **25 s** mellom
  - Pacing: negativ split ønskelig (2. lett, 1. steady)

## Avslutning (5 min)
- 200 easy

## Plan B
- 3×400 eller 2×500 + 2×200

## CSS-merknad
Når CSS er testet: 500 @ CSS+8 s/100 m.

## TP
```
400 WU + 4x50
3x500 @ aerobic 25s rest
200 CD
```
