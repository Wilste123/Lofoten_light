# Skader i utholdenhet — coach-handbok

## Epidemiologi (praktisk)

| Disiplin | Skaderate per 1000 t (indikativ) | William-risiko |
|----------|----------------------------------|----------------|
| Løp | Høyest | **Høy** — comeback + motivasjon |
| Svøm | Skulder | **Medium** — ny volum |
| Sykkel | Lav (sadel/rygg) | Lav–medium ved høyt innendørs |
| Tri kombinasjon | Overbelastning > akutt | **Høy** hvis volumsprang |

## Smerte-skala (bruk i planer)

| 0–10 | Handling |
|------|----------|
| 0–2 | Normal DOMS — ok å trene easy |
| 3–4 | Monitor; ingen hard samme ben |
| 5+ | Stopp hard økt; vurder fysio |
| Lokaliserbar én side | Ikke «løp gjennom» |

## Return-to-play (løp)

| Fravær | Uke 1 retur |
|--------|-------------|
| 3 dager plager | 50 % plan |
| 1 uke | 3×20 min easy |
| 2 uker | Som re-etablering fase 1 |

## Tri-konflikter

- Hard løp + hard sykkel samme dag → unngå i base
- Svøm skulder + mye pull → reduser pull
- Brick for tidlig → knær/fot

## Dokumentasjon

Logg i `profile.md` Begrensninger: side, dato, hva som provoserte.

## Agent

Ved planlegging: **én** risikosetning per uke («denne uken er løp-km +12 % — hold onsdag sykkel easy»).

Se `belastningsstyring-acwr.md`, `lop-skadeprofiler.md`, `forebygging-styrke-mobilitet.md`.

## Belastningsbegrensninger (ikke diagnose)

**Coach justerer load — diagnostiserer ikke.** Røde flagg (traume, nevrologiske utfall, brystsmerter, feber, nattesmerter): stopp hard trening, henvis lege/fysio.

| Utøverbeskrivelse | Typisk load-grep | Unngå |
|-------------------|------------------|-------|
| Kne ved løp | Kutt løp-fart/volum; alternativ | «Menisk»-stempel |
| Akilles | Reduser bakke/sprint | Behandlingsoppskrift |
| Beinhinne / medial smerte | Impact ned | «Bare teip» |
| Korsrygg / «isjas»-beskrivelse | Unngå tung fleksjon under fatigue; forsiktig løp | Nevrologisk diagnose |
| Skulder ved svøm | Meter/paddles ned | Impingement-stempel |
| Mistanke stressfraktur | Ingen impact før medisinsk avklaring | «Rolige joggeturer» som behandling |
| IBS under økt | Forsiktig fueling (`ernaring/`) | GI-diagnose |

Return-to-run: frekvens før varighet før fart; unngå spike (IOC; Gabbett). Styrke kun smertefri ROM (`forebygging-styrke-mobilitet.md`).
