# Svømtrening — øktbibliotek og periodisering

## Ukemønster (standard)

| Økt | Type | Fokus |
|-----|------|--------|
| 1 | Teknikk | Drill, lav puls |
| 2 | Aerob | Kontinuerlig / lange repetisjoner |
| 3 | Kvalitet | CSS / threshold (når test finnes) |

## Øktbibliotek

### Teknikk A (50 min)
```
200 mixed warm-up
8×50 som: 25 drill / 25 swim (catch-up, fingertip, scull)
4×100 pull med buoy @ RPE 4
8×25 kick med board
100 easy
```

### Aerob B (55 min)
```
300 warm-up
3×500 @ RPE 5 (20 s pause) → progresjon til 1×1500
4×50 easy
```

### CSS C (60 min)
```
400 warm-up
8×50 build
10×100 @ CSS + 5 s (15 s siste 2)
200 cool-down
```

### OW sim D (60 min i sjø)
```
10 min shore warm-up
400 easy sighting hver 6 tak
800 steady race pace −5 %
400 cool easy
```

## Periodisering meter/uke (veiledende)

| Fase | Meter/uke | Økter |
|------|-----------|-------|
| Re-etab | 4–6k | 3 |
| Base | 6–9k | 3 |
| Build | 8–12k | 3–4 |
| Spec | 7–10k (mer kontinuerlig) | 3 |

**+10 % meter/uke max** uten recovery.

## Integrasjon tri

- **Ikke** svøm hard dagen før hard løp hvis skuldre ømme
- Morgen svøm + kveld løp = ok for mange
- Svøm samme dag som lang sykkel: svøm **først**

## Pull buoy — coach-regel

Maks **40 %** av volum med buoy; resten full stroke for race transfer.

## Uten CSS-test

Bruk RPE 6–7 på 100-er med 15 s pause; juster når test finnes.
